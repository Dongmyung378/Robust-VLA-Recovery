## 설계 평가

### 확인한 장점

- 무거운 ML 패키지를 핵심 패키지의 가져오기 경로에서 분리해 CI와 설정 검증이 GPU
  없이도 빠르게 실행된다.
- 알 수 없는 key를 허용하지 않아 설정 오타가 조용히 무시되지 않는다.
- 출력 경로의 절대경로와 `..` 이탈을 막아 실행 결과가 프로젝트 밖의 임의
  위치에 기록되는 것을 예방한다.
- 범위 축소 규칙에 맞춰 설정은 네 태스크뿐 아니라 세 태스크 구성도 허용한다.
- 최신 SmolVLA와 LIBERO 통합을 하나의 LeRobot 릴리스로 맞춰 오래된 LIBERO
  원본 환경과의 직접 충돌을 피했다.

### 당시 남은 위험

1. 현재 작업 세션에서는 WSL 배포판 조회 권한이 없어 Linux 환경 존재 여부를
   검증하지 못했다.
2. 시뮬레이션 요구사항은 직접 의존성을 고정했지만 전이 의존성 전체 잠금 파일은
   아직 생성하지 않았다.
3. 6GB VRAM에서 SmolVLA 추론이 실제로 동작하는지는 Day 3부터 Day 6까지 설치와
   짧은 실행으로 확인해야 한다.
4. CI 작업 흐름은 작성하고 로컬에서 같은 명령을 통과했지만 GitHub 원격 실행 결과는
   아직 없다.
